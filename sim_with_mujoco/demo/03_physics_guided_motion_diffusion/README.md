# 03. Physics-Guided Motion Diffusion

This experiment uses MyJoCo as a trajectory generator and validator. It collects
physics-valid gait rollouts from randomized CPG-residual controllers, then trains
a tiny diffusion-style model to generate short future joint-target sequences.

## Research Question

Can we learn a compact motion prior from trajectories generated by our own
physics simulator instead of motion-capture data?

## Files

- `collect_rollouts.py`: creates `motion_rollouts.npz` from randomized physics rollouts.
- `diffusion_model.py`: tiny conditional denoising network.
- `train_tiny_diffusion.py`: trains a DDPM-style sequence denoiser.
- `sample_diffusion_plan.py`: samples joint-target sequences from a checkpoint.
- `config.json`: default data/model settings.
- `REFERENCES.md`: related work.

This experiment reuses the demo-local walker asset in
`../01_cpg_residual_natural_walker/toy_walker.xml`. It does not modify files
outside `sim_with_mujoco/demo`.

## Run

Collect a small dataset:

```bash
source venv/bin/activate
python sim_with_mujoco/demo/03_physics_guided_motion_diffusion/collect_rollouts.py --episodes 64
```

Train the tiny diffusion model:

```bash
python sim_with_mujoco/demo/03_physics_guided_motion_diffusion/train_tiny_diffusion.py
```

Sample a plan:

```bash
python sim_with_mujoco/demo/03_physics_guided_motion_diffusion/sample_diffusion_plan.py
```

## Portfolio Angle

The key distinction from FreeMusco is that this is not a musculoskeletal latent
controller. It is a physics-guided motion generation pipeline: simulate,
filter/score, learn a motion prior, then validate generated plans back in
MuJoCo.
